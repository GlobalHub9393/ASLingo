Training mode

Sign naturally. If ASLingo is right, tap This is ___. If it is wrong, choose the letter you actually signed. That landmark example is remembered immediately on this device and, when signed in, added to ASLingo's shared training memory.

Global learning has a guardrail.One person's correction is stored globally, but it does not override everybody's recognizer by itself. Shared corrections only influence recognition when nearby examples from multiple contributors agree.

J and Z are intentionally excluded. They require a temporal motion recognizer.
